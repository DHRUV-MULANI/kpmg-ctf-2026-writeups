MIG-2011-004 -- legacy-03 P2V Consolidation Author: R. Alvarez (Infra) Date: 2011-06-14 Status: Closed Summary ------- Physical host legacy-03 (Debian 4.0 "etch", originally provisioned 2007-11-14 by R. Alvarez per provisioning checklist v3) has been converted to a virtual machine and consolidated onto the ops-gw01 hypervisor cluster as part of the 2011 datacenter footprint reduction project. The physical chassis has been decommissioned; the guest continued running under the original hostname until its DB role was fully retired in 2019 (see server inventory). Migration notes ---------------- - Filesystem and package state carried over as-is via dd image + rsync delta, no reinstall performed. - SSH host keys AND the svc-legacydb user keypair from the original 2007-11-14 provisioning were carried over without regeneration, to avoid re-establishing trust with dependent monitoring/cron systems that pin the host key fingerprint. This was flagged as technical debt at the time (see ticket backlog) but never scheduled for remediation before the DB role itself was retired. - Post-migration, SSH access for svc-legacydb briefly broke due to a restore-order issue -- see TICK-4471 for details and resolution. - A partial tape restore of /etc/ssh, /home/svc-legacydb and /var/log/provision.log from backup set B-2007-11 was pulled for troubleshooting during that incident and left in cold storage for audit purposes. Not linked from the main archive index. Ask infra if you need the exact path -- it's not repeated here. Outcome ------- Migration considered successful. legacy-03 continued serving as a DB read-replica under ops-gw01 until full retirement in 2019. No further action taken on the carried-over-keys tech debt item since the account was scheduled for deprovisioning along with the DB role.
